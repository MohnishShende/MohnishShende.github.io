nmap-llm

An offline workflow for Nmap planning, execution, XML parsing, and local-LLM-assisted triage reporting.

Working prototypePython working prototype

View repository ↗

Purpose

Keep scan execution deterministic; use the model for bounded assistance.

nmap-llm is an offline Python prototype that connects scan planning, Nmap execution, XML parsing, and local-LLM-assisted triage reporting. The public repository contains modules for configuration, model interaction, parsing, scanning, and utilities.

Pipeline

Implementation

Language
Python modules with XML, JSON, and Markdown handling.
Scanner
Nmap execution and result parsing.
Model
Ollama with a local model integration documented by the repository.
Output
Structured triage material and Markdown reporting.

Limitations

A working prototype with validation work remaining.

No automated test suite was observed during the evidence review. The site therefore does not claim automated coverage. Safety behavior, command constraints, failure handling, and adversarial model output should be validated further before broader operational use.
